# 🧠 tg-rag-mem-bot

Мощный Telegram-бот с искусственным интеллектом, обладающий абсолютной долгосрочной памятью на основе векторной базы данных (RAG). Бот умеет не только вести осмысленный диалог, вспоминая детали из прошлых бесед, но и работать с файлами, аудио и интернетом.

## 🚀 Основные возможности

- **Абсолютная память (RAG)**: Использование Qdrant и локальных моделей эмбеддингов для сохранения всей истории общения. Бот сам извлекает нужные факты из прошлого, когда это необходимо.
- **Голосовые сообщения**: Нативная интеграция с **Groq Whisper** (`whisper-large-v3`) для мгновенной и точной расшифровки голосовых сообщений.
- **Веб-скрейпинг**: Отправьте боту любую ссылку, и он автоматически извлечет из неё чистый текст статьи с помощью [Jina Reader API](https://jina.ai/reader/).
- **Умный поиск**: Команда `/search <запрос>` позволяет боту искать информацию в интернете в реальном времени через Jina Search и добавлять её в контекст ответа.
- **Поддержка файлов**:
  - Текстовые документы (`.txt`, `.md`, `.py`, `.json`, `.csv`).
  - Офисные документы (`.docx`) с защитой от Zip-бомб.
  - PDF-документы (распознавание через Jina Reader с локальным фолбэком на `pypdf`).
- **Безопасность**: Встроенный Allow-list для приватного использования (доступ только для разрешенных пользователей и групп) и защита от превышения лимитов API (батчинг эмбеддингов с экспоненциальным бэкоффом).

## 🛠 Технологический стек
- **Python 3.10+** (Aiogram 3.x)
- **OpenRouter** (Опросы LLM: DeepSeek, Claude, GPT и др.)
- **Qdrant** (Векторная база данных)
- **Groq API** (Сверхбыстрое распознавание голоса)
- **Jina API** (Парсинг веб-страниц, PDF и поиск)

## ⚙️ Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/telegram-rag-bot.git
cd telegram-rag-bot
```

### 2. Настройка окружения
Скопируйте пример конфигурационного файла и заполните его своими ключами:
```bash
cp .env.example .env
```
В файле `.env` необходимо указать:
- `TELEGRAM_BOT_TOKEN` — токен от [@BotFather](https://t.me/BotFather)
- `OPENROUTER_API_KEY` — ключ от [OpenRouter](https://openrouter.ai/)
- `GROQ_API_KEY` — ключ от [Groq](https://groq.com/) (для голосовых сообщений)
- `JINA_API_KEY` — ключ от [Jina](https://jina.ai/) (для ссылок и поиска)
- `ALLOWED_USERS` — (Опционально) ваш Telegram ID для защиты бота от чужаков.

### 3. Запуск через Docker (Рекомендуется)
Бот поставляется с готовым `docker-compose.yml`, который поднимет и самого бота, и векторную БД Qdrant.
```bash
docker-compose up -d --build
```

### Запуск локально (Без Docker)
Если вы хотите запустить скрипт напрямую:
1. Установите зависимости: `pip install -r requirements.txt`
2. Скачайте локальные модели: `python download_models.py`
3. Убедитесь, что у вас установлен `ffmpeg` (для работы с аудио).
4. Запустите локально инстанс Qdrant на порту 6333.
5. Запустите бота: `python bot.py`

## 🛡 Безопасность
Бот использует `SecurityMiddleware`, который блокирует все сообщения от пользователей, чьи ID не указаны в `ALLOWED_USERS` и `ALLOWED_GROUPS`. Если оставить эти поля пустыми, бот будет публичным.
